# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Общие правила курса — в `../CLAUDE.md`; здесь только то, что касается этого проекта.

## Что это

Учебный консольный скрипт заметок: добавить строку, показать все, изменить и
удалить по номеру. В будущем может вырасти в небольшой сервис.

## Установка, запуск, проверка

Команды — в `README.md`; здесь не дублировать.

Ставить **только с `-e`**: путь к данным считается от `src/notes.py`
(`parents[1]` — корень проекта). При обычной установке модуль копируется в
`.venv`, и путь укажет внутрь окружения.

## Отступления от раскладки курса

- **Один модуль `src/notes.py`, а не пакет `src/<пакет>/`** — условие
  владельца: задание первого шага — один файл. Поэтому нет `__main__.py` и
  `ports.py` (`../CLAUDE.md`, раздел «Раскладка»): сборка частей — в `main()`,
  хранение — функциями без протокола. Пакетом станет, когда проект пойдёт в
  сервис. Сборка одиночного модуля — `only-include` + `sources` в
  `pyproject.toml`.
- **Docker не нужен** — проект учебный, в контейнере его не запускают;
  `docker/` не заводить.

## Устройство `src/notes.py`

Три слоя, каждый в своих функциях:

- **Правила** — `add_note`, `delete_note`, `edit_note`, `format_notes`:
  чистые функции, принимают список и возвращают новый, не трогают ни файл, ни
  консоль. Ошибка ввода — `ValueError` с текстом для человека. Номер заметки
  для человека начинается с 1; проверка номера — `_check_number`, разбор
  строки в номер — `parse_number`.
- **Хранение** — `load_notes`, `save_notes`. Сбой чтения или чужая структура
  файла — `StorageError`.
- **Консоль** — `main(path)`, единственное место с `input`/`print`.

При переходе к сервису правила остаются, меняются хранение и `main()`.
Правила не переносить в обработку ввода или в функции хранения.

## Хранение в `data/notes.json`

- `NOTES_FILE` — `data/notes.json` в корне проекта; `data/` целиком в
  `.gitignore`, создаётся первой записью. Формат — JSON-список строк,
  `ensure_ascii=False`. Нет файла — пустой список.
- Запись целиком после каждого изменения: во временный `notes.json.tmp`, затем
  `os.replace` — прерванная запись не портит прежний файл.
- Испорченный или чужой файл при запуске: выход с кодом 1 и сообщением, файл
  **не перезаписывается** — иначе заметки пропадут. Это поведение не менять.
- В `main()` новый список присваивается `notes` только после успешного
  `save_notes`: при `OSError` изменение отменяется, память не расходится с
  файлом.
- `data/` — личные данные: не читать и не печатать содержимое.

## Тесты

`tests/test_notes.py` импортирует установленный модуль и покрывает три слоя.
Меню проверяется через `notes.main(tmp_path / "notes.json")`; `feed()`
подменяет `input` и возвращает заданные вопросы — по ним видно, о чём
программа спрашивала. Боевой `data/` тесты не трогают: только `tmp_path`.
