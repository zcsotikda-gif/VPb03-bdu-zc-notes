# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Общие правила курса — в `../CLAUDE.md`; здесь только то, что касается этого проекта.

## Что это

Учебный консольный скрипт заметок: добавить строку, показать все, удалить по
номеру. В будущем может вырасти в небольшой сервис.

## Запуск

```
/opt/homebrew/opt/python@3.12/bin/python3.12 notes.py
```

Зависимостей нет, только стандартная библиотека; `.venv` пока не нужен.

## Отступление от раскладки курса

По заданию код живёт **в одном файле `notes.py`** в корне, а не в src-layout
из `../CLAUDE.md`. Не переносить в `src/`, не добавлять `pyproject.toml`,
`tests/` и Docker без просьбы владельца.

## Устройство `notes.py`

Три слоя, каждый в своих функциях:

- **Правила** — `add_note`, `delete_note`, `format_notes`: чистые функции,
  принимают список и возвращают новый, не трогают ни файл, ни консоль. Ошибка
  ввода — `ValueError` с текстом для человека. Номер заметки для человека
  начинается с 1; перевод в индекс — внутри `delete_note`.
- **Хранение** — `load_notes`, `save_notes`. Сбой чтения или чужая структура
  файла — `StorageError`.
- **Консоль** — `main(path)`, единственное место с `input`/`print`.

При переходе к сервису правила остаются, меняются хранение и `main()`.
Правила не переносить в обработку ввода или в функции хранения.

## Хранение в `notes.json`

- Файл лежит рядом со скриптом (`NOTES_FILE`), формат — JSON-список строк,
  `ensure_ascii=False`. Нет файла — пустой список.
- Запись целиком после каждого изменения: во временный `notes.json.tmp`, затем
  `os.replace` — прерванная запись не портит прежний файл.
- Испорченный или чужой файл при запуске: выход с кодом 1 и сообщением, файл
  **не перезаписывается** — иначе заметки пропадут. Это поведение не менять.
- В `main()` новый список присваивается `notes` только после успешного
  `save_notes`: при `OSError` изменение отменяется, память не расходится с
  файлом.
- `notes.json` — личные данные: не читать и не печатать его содержимое.

## Проверка

Тестов нет. Ручной прогон делать на временном файле, а не на боевом
`notes.json`: `main()` принимает путь, поэтому

```
python3.12 -c "import sys; sys.path.insert(0, '<проект>'); from pathlib import Path; import notes; notes.main(Path('<scratchpad>/t.json'))"
```

с вводом через `printf '1\nтекст\n2\n0\n' |`.
